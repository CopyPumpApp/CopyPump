# CopyPump Maintainers

## Project owner

- **@Garbuz7** — project owner and final maintainer for the public CopyPump repository.

## Repository model

`CopyPumpApp/CopyPump` is the public collaboration surface for CopyPump. External contributors may open issues, forks, and pull requests under the repository license and contribution rules.

The private engineering repository, proprietary trading core, unreleased internal systems, private operational evidence, credentials, wallet material, and security-sensitive implementation details are outside this public repository and are not transferred or opened by public contributions.

## Review authority

Public contributions are welcome, but merging, release decisions, security-sensitive changes, licensing changes, ownership/permission changes, and changes to project claims remain subject to final maintainer review.

No contributor should be granted administrative ownership or access to private project assets solely because they contributed code or documentation.

See `.github/CODEOWNERS`, `CONTRIBUTING.md`, `SECURITY.md`, and `LICENSE` for the operational contribution boundary.
