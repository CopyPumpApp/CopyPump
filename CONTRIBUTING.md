# Contributing to CopyPump

CopyPump is currently in technical alpha and active security hardening. The project is not yet operating as a fully open-source contribution workflow.

## Before contributing

Please do not submit unsolicited large code changes or architectural rewrites without prior coordination.

For now, the most useful contributions are:

- clear bug reports with reproducible steps;
- documentation corrections;
- UX and accessibility observations;
- Solana Devnet execution and reconciliation findings;
- security reports sent privately according to `SECURITY.md`.

## Bug reports

A useful bug report should include:

- the feature or screen involved;
- expected behavior;
- observed behavior;
- exact reproduction steps;
- browser / environment details when relevant;
- screenshots or logs with secrets removed.

Never include seed phrases, private keys, API keys, session secrets, encryption keys, or production user data.

## Security issues

Do not report exploitable vulnerabilities in public issues or discussions. Follow the private reporting instructions in `SECURITY.md`.

## Development status

CopyPump is currently focused on Solana Devnet hardening. Mainnet execution remains intentionally blocked until the required safety and verification work is complete.

Public contribution rules may expand as the project reaches a more stable stage.
